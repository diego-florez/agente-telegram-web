Política de privacidad

Última actualización: 10 de octubre de 2026

Qué es esta aplicación

Agente Telegram es un proyecto personal de aprendizaje. Solo lo usa su autor, con una cuenta de Google de pruebas.

Qué datos de Google usa

  • Gmail: leer correos para responder a preguntas del usuario, y redactar o enviar correos solo cuando el usuario lo confirma.
  • Google Calendar: consultar eventos y crearlos o modificarlos solo cuando el usuario lo confirma.

Cómo se usan y se guardan

  • Los datos se usan únicamente para responder a las peticiones del propio usuario.
  • Los tokens de acceso se guardan cifrados en un servidor privado.
  • No se venden, no se comparten con terceros y no se usan para publicidad.
  • Para generar las respuestas, el texto necesario se envía a la API de Google Gemini.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Para pedir que se borren los datos guardados, escribe a la dirección de contacto.
